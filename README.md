# Memorial Landing — «Елена Ветрова»

Элегантный одностраничный мемориальный лендинг с премиальным ностальгическим дизайном.
Чистый HTML5 / CSS3 / JavaScript с плавными анимациями (GSAP + AOS).

## Особенности дизайна
- **Единая типографическая система**: Playfair Display для заголовков и чисел, Cormorant Garamond для основного текста, Inter для UI-элементов
- **Унифицированная цветовая палитра**: Тёплые бронзово-золотые акценты, кремовые фоны, мягкие коричневые оттенки для ностальгического настроения
- **Премиальные карточки воспоминаний**: Элегантный дизайн с градиентными фонами, декоративными рамками и индивидуальными аватарами близких
- **Сложная сетка таймлайна**: 5 равных колонок с центрированными точками и стандартизированной типографикой чисел
- **Естественный слайдер**: Drag-to-scroll с инерцией для плавной навигации по воспоминаниям

## Секции
- **Hero** — имя, портрет, даты жизни, фоновый слой и лёгкий параллакс
- **Биография** — три абзаца с аккуратной типографикой и декоративным элементом sprig.png
- **Галерея** — сетка с мягкими hover-эффектами и фоном sophisticated beige
- **Таймлайн** — вертикальная линия с точками и ключевыми годами в 5 равных колонках
- **Воспоминания** — премиальные карточки-цитаты близких с индивидуальными аватарами и ностальгическим стилем
- **Наследие** — статистика с унифицированной типографикой чисел
- **Footer** — портрет, цитата, даты жизни с координированной типографикой

## Технологии
- HTML5, CSS3 (Grid, CSS-переменные, адаптив)
- JavaScript (модуль-обёртка, без сборщиков)
- [GSAP](https://greensock.com/gsap/) + ScrollTrigger — hero-интро и параллакс
- [AOS](https://michalsnik.github.io/aos/) — reveal при скролле
- Google Fonts: Playfair Display, Cormorant Garamond, Inter

Библиотеки подключаются по CDN — интернет нужен только для их загрузки.
Учитывается `prefers-reduced-motion`: анимации отключаются для чувствительных пользователей.

## Структура
```
memorial-landing/
├── index.html
├── css/style.css
├── js/script.js
└── images/           # Изображения (портрет, аватары друзей, галерея, sprig.png)
```

## Запуск
Откройте `index.html` двойным кликом, либо запустите локальный сервер:

```bash
python -m http.server 5500
# затем откройте http://localhost:5500
```

Замените изображения в `images/` на реальные фотографии (сохранив имена файлов),
и отредактируйте тексты в `index.html` под нужного человека.
